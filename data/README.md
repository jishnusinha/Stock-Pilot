# StockPilot datasets

This repository uses **two isolated data tracks**.

## SYNTHETIC_DEMO (default application)

- Generated by `python -m app.cli bootstrap` / `seed`
- Stored in `backend/data/stockpilot.db`
- Powers Command Center, Inventory Analytics, Simulator, Reorders, and the ten-agent synthetic ML stack
- Money is integer **paise** (display ₹)
- Risk / supplier outcomes are labeled `SIMULATED_SUPPLY`

Do not mix synthetic rows into the real-retail evaluation track.

## REAL_RETAIL_UCI (evaluation track)

Official **UCI Online Retail** transactions (dataset 352), used only for scientifically honest forecast benchmarking.

| Path | Purpose |
|------|---------|
| `data/real/uci_online_retail/raw/` | Official `Online Retail.xlsx` (gitignored; downloadable) |
| `data/real/uci_online_retail/processed/` | Cleaned transactions, daily sales, products |
| `data/real/uci_online_retail/splits/` | Chronological train / validation / test CSVs |
| `data/real/uci_online_retail/samples/` | Small inspectable samples for interviews |
| `experiments/real_data/uci_online_retail/` | Models + evaluation reports (isolated from demo artifacts) |

### Provenance

- Name: Online Retail  
- Creator: Daqing Chen  
- DOI: https://doi.org/10.24432/C5BW33  
- License: CC BY 4.0  
- Page: https://archive.ics.uci.edu/dataset/352/online+retail  
- Currency: **GBP** (never labeled as INR)

### Reproduce

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python -m app.cli real-data-download
python -m app.cli real-data-prepare --max-products 100 --seed 42
python -m app.cli real-data-train --threads 2 --seed 42
python -m app.cli real-data-evaluate
python -m app.cli real-data-status
```

Or: `python -m app.cli real-data-all --max-products 100 --seed 42 --threads 2`

If download is blocked, place the official XLSX at  
`data/real/uci_online_retail/raw/Online Retail.xlsx`  
and re-run prepare.

### What this dataset does **not** provide

- Inventory on-hand history  
- Supplier promised/actual delivery dates  
- Verified stockout events  
- Store opening calendars / lost sales  

Therefore REAL_RETAIL_UCI does **not** validate Supplier ETA, Stockout Risk, Excess Risk, or reorder optimization. Those remain on the synthetic demo track.
